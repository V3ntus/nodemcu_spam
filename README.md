# NodeMCU_spam

Forked/inspired by https://github.com/Jeija/esp32-80211-tx

Demonstrates usage of `esp_wifi_80211_tx` and raw 802.11 beacon frame injection.

Purpose of this code is to generate noise from fake hotspots, thwarting physical tracking
sensors out in the world (Flock cameras, surveillance ,etc.).
